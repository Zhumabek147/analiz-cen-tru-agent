# Анализ цен ТРУ

ИИ-агент проверяет коммерческое предложение (КП) подрядчика по рынку: разбирает позиции, сам находит цены в Казахстане, России и мире, показывает ближайшие варианты, ориентир, разницу и потенциальную экономию, готовит заключение и проект письма подрядчику.

**Открыть:** https://zhumabek147.github.io/analiz-cen-tru-agent/ — адрес сразу ведёт к агенту на claude.ai.

## Как пользоваться

- Нужен аккаунт Claude с подпиской. Агент работает в её рамках, ключ API и отдельная оплата не нужны.
- Доступ к агенту выдаёт его владелец.
- Для поиска цен подключите бесплатный коннектор Parallel Search: claude.ai → Settings → Connectors.
- Загрузите КП (текст, Excel, фото или PDF) и нажмите «Проверить КП».

Оценка носит справочный характер и не является официальным заключением о рыночной цене.
