# Анализ цен ТРУ

ИИ-агент проверяет коммерческое предложение (КП) подрядчика по рынку: разбирает позиции, сам находит цены в Казахстане, России и мире, показывает ближайшие варианты, ориентир, разницу и потенциальную экономию, готовит заключение и проект письма подрядчику.

**Открыть:** https://zhumabek147.github.io/analiz-cen-tru-agent/

## Как пользоваться

1. Создайте свой ключ на [platform.claude.com → API Keys](https://platform.claude.com/settings/keys) (вариант «Somewhere else») и пополните баланс.
2. Откройте страницу, вставьте ключ в поле «00 Ваш ключ Anthropic API» и нажмите «Сохранить».
3. Загрузите КП (текст, Excel, фото или PDF) и нажмите «Проверить КП».

Расходы идут с баланса владельца ключа: проверка КП из 5–6 позиций — примерно 1–3 доллара.

## Безопасность

- Ключ хранится только в вашем браузере и отправляется только в `api.anthropic.com`. Сервера у этой страницы нет.
- На общих компьютерах снимайте галочку «Запомнить на этом компьютере».
- Тексты КП обрабатывает Claude (Anthropic). Перед работой с реальными закупками согласуйте это с ИТ или службой безопасности.
- Оценка носит справочный характер и не является официальным заключением о рыночной цене.

## Файлы

- `index.html` — страница агента со встроенной прослойкой «свой ключ».
- `byok-shim.js` — исходник этой прослойки: вызовы Claude из браузера, поиск цен, курсы Нацбанка РК, поле для ключа.
